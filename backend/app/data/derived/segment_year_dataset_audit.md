## Reminders for anyone using this table

- Do not train/test split randomly by row: split by `segment_id` (group split) — see the inspection doc's Section 7.3.
- Rainfall features are contemporaneous with the row's year, not pre-event-only, for events without a day-precise date (Section 9 caveat).
